# PPC Campaign Setup Standard

Every paid search campaign must follow a consistent setup process so that performance can be reviewed across accounts.

Campaign setup stages:

1. Confirm conversion tracking.
2. Define campaign goal.
3. Select campaign type.
4. Build keyword groups.
5. Draft responsive search ads.
6. Add negative keyword lists.
7. Configure location and language targeting.
8. Define budget and bidding strategy.
9. Run quality assurance before launch.

The PPC lead must not launch a campaign until conversion tracking has been checked. If tracking is unavailable, the campaign can be built in draft state but must remain paused.

Required QA checks:

- Campaign name follows naming convention.
- No broad match keywords are used without documented reason.
- Landing page matches ad intent.
- At least one negative keyword list is attached.
- Final URLs use HTTPS.
- Budget aligns with the approved monthly allocation.
