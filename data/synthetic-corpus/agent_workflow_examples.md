# Agent Workflow Examples

ModelWeave demonstrates configurable language-model workflows through role-based agents.

Example workflow: Project Question Answering

1. Router Agent determines whether the question concerns PPC, SEO, reporting, or client onboarding.
2. Research Agent retrieves relevant knowledge-base documents.
3. Analyst Agent extracts decisions, requirements, risks, and missing information.
4. Writer Agent prepares a concise answer for the user.
5. Verifier Agent checks whether the answer is supported by retrieved sources.

Example workflow: Monthly Report Drafting

1. Reporting Agent reads performance notes and metric tables.
2. PPC Agent explains paid media changes.
3. SEO Agent explains organic search changes.
4. Writer Agent produces the report in business language.
5. Translator Agent can prepare a Ukrainian supervisor-facing summary.
