# Agent Instructions

Before doing work in this project, read `PROJECT_MEMORY.md`.

After meaningful changes, update `PROJECT_MEMORY.md` with:
- What changed
- Why it changed
- Files touched
- Commands or checks run
- Open questions or next steps

Keep progress updated throughout the work, not only at the end. When a task has multiple steps, record current status, completed steps, blocked items, and next actions in `PROJECT_MEMORY.md` as the work moves forward.

Keep edits factual and concise. Do not remove prior memory unless it is clearly obsolete; instead, mark it superseded with a date.
