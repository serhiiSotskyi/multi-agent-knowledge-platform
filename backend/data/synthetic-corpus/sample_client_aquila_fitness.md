# Sample Client: Aquila Fitness Studio

Aquila Fitness Studio is a fictional local fitness business with two city-center locations. The client wants to increase trial class bookings and improve search visibility for personal training services.

Commercial goals:

- Increase trial class bookings.
- Reduce wasted PPC spend on irrelevant searches.
- Improve local organic visibility.
- Build a content plan around beginner fitness questions.

Known constraints:

- Monthly PPC budget is limited.
- The website has slow mobile pages.
- Conversion tracking exists but has not been verified.
- The client cannot make large website changes during the first month.

Recommended first workflow:

1. Verify conversion tracking.
2. Run local SEO audit.
3. Build tightly scoped brand and service campaigns.
4. Create landing page recommendations.
5. Prepare first-month report template.
